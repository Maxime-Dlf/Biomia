# Questions de clarification — Phase 0 (synthèse)

Ce document récapitule les **résolutions actées** et les **points encore ouverts**.
La référence normative des règles est
[`regles-source-de-verite.md`](regles-source-de-verite.md:1).

---

## 1. Résolutions actées

| # | Question | Décision |
|---|---|---|
| R1 | Périmètre | **Tier A uniquement** pour la v1 |
| R2 | 5ᵉ type de jeton | **Étoile** (barème progressif validé) |
| R3 | Ronds : majoritaire ou individuel | **Individuel** |
| R4 | Contrôle d'un environnement | Par la pose d'une **tuile** qui l'étend |
| R5 | Reroll | Relance des **jetons identiques** (3 manuel, 4 auto) + règles anti-boucle |
| R6 | Regarnissage du marché | Par emplacement (tuile choisie + jeton choisi remplacés) |
| R7 | Nombre de joueurs | **8 recommandés** (plus possible, moins confortable) |
| R8 | Bouton retour | **Rembourse tout sauf les rerolls** |
| R9 | Ordre de jeu | **Ordre des sièges** ou **aléatoire**, via une option |
| R10 | Composition de la pool | Ajouter les jetons des types acceptés par chaque tuile |
| R11 | Équilibrage des tuiles | Ratio **1:2:2** (1/2/3 jetons), couleurs et formes équilibrées |
| R12 | Jeton non plaçable | Halo rouge, 2 options (ne pas jouer / payer 1 joker), pas de retirage |
| R13 | « Ne rien choisir » | Le jeton associé est renvoyé à la pool et remplacé |
| R14 | Minuteur | **60 s** (15–180 s), serveur joue aléatoirement sans dépenser les jokers |
| R15 | Marché (joker payé) | Seuls la tuile et le jeton choisis sont remplacés ; le jeton associé reste |
| R16 | Triangles (ligne droite) | Un des 3 axes hex (6 directions) |
| R17 | Cœurs (cycles) | **Cycles permis**, seuls les cycles triangulaires directs invalident |
| R18 | Ancienneté | Mesurée au **dernier agrandissement** (pas à la création) |
| R19 | Équipes | Tailles **illimitées**, option **50/50 aléatoire**, petite équipe rejoue |
| R20 | Modularité | Mécaniques **désactivables** sans tout casser, options accessibles |
| R21 | Équilibrage des jetons | Étoile progressive, Triangle prolongé (**validé**) |
| R22 | Unicité des jetons | 1 jeton = 1 chaîne/montage ; support (voisins d'étoile) illimité ; briser exige plus grand + tier le permet |
